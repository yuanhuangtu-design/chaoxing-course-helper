# 课程续播助手（Edge 本地扩展）

适用于《马克思主义与当代科技》（课程编号 267281064）。按正常播放累计时长，自动操作播放器和“下一节”按钮。

## 安装与使用

1. 解压压缩包到固定位置。
2. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择**直接包含 manifest.json 的文件夹**。
4. 回到这门课的具体章节页面。点击扩展图标，选择速度，再点“开始续播”。
5. 如果自动播放受浏览器限制，手动点击一次视频播放，再点击开始。
6. 保持浏览器与课程标签页打开、电脑不要休眠。弹窗可以关闭。

结束时回课程目录核对 35/35。遇到测验、验证或错误时，请手动处理后重新开始。

Microsoft 官方安装说明：
https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/getting-started/extension-sideloading

## 自动化范围

- 同节多个视频依次播放，一次只接管一个视频。
- 优先通过播放器按钮切换到所选速度；无法切换时显示实际速度，沿用当前速度。
- 只有页面明确显示视频任务全部完成，才点击“下一节”。不根据时间估算伪造完成。
- 网站需要作答、验证，视频意外暂停或卡住时停止；“停止并暂停”可随时停止接管。
- 浏览器不允许自动播放、后台受限、网络卡顿或电脑休眠时，可能需要手动恢复。
- 如果跨域播放器无法对应到任务标记，采用顺序播放至结束的保守处理，可能额外播放已完成的视频。
- 只处理可识别的视频任务，不提交测验，不处理验证码，不跳过网站的学习要求。

## 权限

仅请求两个课程域名的页面访问权限：

- `https://mooc1.chaoxing.com/*`
- `https://mooc2-ans.chaoxing.com/*`

启动时进一步核对指定课程编号。`scripting` 用于读取任务标记并操作页面按钮；`activeTab` 用于选择当前课程页；`storage` 只保存当前浏览器会话中的本地运行状态；`alarms` 用于后台续播检查。没有外部服务器、账户凭据读取、数据上传、记分接口调用、播放进度改写或防检测逻辑。

## 检查状态

源代码是独立的 Manifest V3 扩展，无需安装依赖或构建。已完成决策与后台模拟连续续播检查，结果见包内 `CHECKS.zh-CN.md`。

在仓库目录执行 `npm test` 可重新运行本地逻辑检查；不需要安装第三方依赖。浏览器 DOM 模拟页面位于 `tests/extension-browser-tests.html`，这些模拟检查不能代替真实课程的实测。

当前版本尚未安装到真实 Edge 环境进行整节连续切换验证。安装后应先观察一次“播放 → 平台标记完成 → 下一段/下一节”的完整过程。网站改版或播放器来自其他域名时可能无法识别，会停止并提示。

## 文件

- `core.js`：根据页面任务状态作出续播决定。
- `dom.js`：读取显示状态，操作播放器与下一节按钮。
- `worker.js`：管理单一课程标签页、异常停止和浏览器会话状态。
- `pulse.js`：唤醒本地后台检查。
- `popup.*`：开始、停止和状态界面。
- `guide.*`：本地使用说明。
- `tests/`：本地逻辑检查与模拟页面。
